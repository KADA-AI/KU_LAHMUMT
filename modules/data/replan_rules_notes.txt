재계획 상황 구현 내용

1. 0802 강제명령

1) execute 2(강제귀환)일때 -> 가용정보 업데이트 후 -> 바로 재계획 들어감
 * 재계획 규칙
  - 지금까지 한 임무를 기반으로 새로운 영역 생성 -> 임무 수행 상태에 대해 영역을 모니터링하고 추후 쓰는 방안이 필요함(계획정보, 그리고 찍어야하는 정보로 만들면 될 듯)
  - 가용한 기체에대해 할당
  - 임무 재계획 수행
  => 일단 임시로, 지금까지 한 협업기저 임무 파악 후, 협업기저임무 다시 계획함 


2) execute 1(강제대기)일때 -> 20초간 일단 지켜봄 -> 20초 내에 execute에 대한 다른 명령 없을경우 재계획 들어감
 * 재계획 규칙
  - 지금까지 한 임무를 기반으로 새로운 영역 생성
  - 가용한 기체에대해 할당
  - 임무 재계획 수행

3)  execute 3(임무로 복귀)일때 -> 해당 소티 개별임무에 다른 비행체와의 임무 종료시간 차이가 심하지 않은지 확인 -> 임무 재할당 필요여부 식별
ㄴ 필요할 경우? -> 남은 영역을 다른 무인기가 같이 해주는 형태로
ㄴ 필요 없을경우? -> 그냥 남은거 그대로 하게끔(재계획 안함) 
ㄴ 이미 앞의 상황으로 인해 임무를 하고있는데 갑자기 투입됐다?? -> 해당 무인기 위치보고 -> 임무 지점 이동 시간 계산 -> 다른 무인기의 임무 프로그래스 예측해보고 30퍼 미만이면 한것까지만 하고 남은 부분 재계획 하는걸로
